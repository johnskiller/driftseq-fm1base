# GLOBAL page (GLO+HOME): tempo, both swing halves, the GM switch, Bluetooth.
#
# The page's contract in one line: everything here is one number for the whole
# instrument, it is rare enough to live behind a chord, and nothing on it
# records into the jam ring.
#
# Geometry: 5 rows at y30 + 24*i, labels x12 (FONT_S), values x100 (FONT_B).
# Door: GLO+HOME on the press edge (GLO is latched by ui_input, never dispatched).
# Leave: a bare HOME, the same gesture every page uses.

wait 600
expect mode 0
expect bpm 120
expect gl_gm 1
expect gm_alloff 0

# The PATTERN reading is the packed size of the pattern summed track by track
# (the page cannot afford a whole store object of buffer). 146 B is the demo's
# own packed size, the same number tests_engine/test_engine.c compares against
# ds_pack_pattern(whole) - this pins the page's arithmetic to the packer's.
expect gl_pat_bytes 146

# ---- the door ----
press GLO
press HOME
release HOME
release GLO
wait 20
expect mode 5
expect gl_row 0
# HOME while the page is up must not also toggle HOME/GRID underneath it
tap HOME
wait 10
expect mode 0
# and the chord works from anywhere, not only from HOME
tap SEQ
wait 10
expect mode 1
press GLO
press HOME
release HOME
release GLO
wait 20
expect mode 5

# ---- the GM switch: CC123 on the way out, then the feed closes ----
# A two-state value is a SLIDER, not a toggle (John 2026-10-30: "第一页的GM...都
# 没有做到盲拧效果"): counter-clockwise asks for OFF, clockwise for ON, and a
# detent towards the state it is already in does nothing. The old code flipped on
# ANY detent, so turning left turned it on.
turn K1 2
wait 5
expect gl_row 2
expect gl_gm 1
turn K2 1
wait 5
expect gl_gm 1                   # right, already ON: nothing to do
turn K2 -1
wait 5
expect gl_gm 0                   # left asks for OFF
expect gm_alloff 1
turn K2 -1
wait 5
expect gl_gm 0                   # left again: still OFF, and no second panic
expect gm_alloff 1
# zero the window, run a full pattern: nothing reaches the synth
expect gm_reset 0
tap PLAY
wait 700
tap PLAY
wait 100
expect gm_noteons 0
# back on: the same run does reach it
turn K2 1
wait 5
expect gl_gm 1                   # right asks for ON
expect gm_reset 0
tap PLAY
wait 700
tap PLAY
wait 100
expect gm_noteons >0

# A device row's value IS the link, and K2 is the knob that changes a value on a
# settings page (docs/UI_GRAMMAR.md rule 1). The LIST is K1's job and the VERB is
# K2's: picking a device with K1 is navigation, turning K2 is the commitment.

expect gl_ble 1
